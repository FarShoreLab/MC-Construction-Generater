# Minecraft 地形自适应建筑群生成系统 · 部署与使用指南

欢迎使用**地形自适应建筑群生成系统（Minecraft Terrain-Adaptive Settlement Generator）**！  
本系统彻底解决了 Minecraft 原版或传统生成算法中“建筑地基悬空”、“大半个房子埋入山体”、“道路笔直撞悬崖”的问题，并支持游戏内 2D 鸟瞰图战术视口、区域框选、自然语言提示词驱动与土方平衡护坡施工。

---

## 一、 系统架构与产物说明

本项目采用高内聚、低耦合的多模块分层架构：

*   **`core-planner`（算法与规划核心）**：纯数学几何库，零 Minecraft 依赖。负责 2.5D 高程矩阵分析、坡度各向异性 A* 道路规划、OBB 地块切分与最佳水平标高求解。可脱离游戏完全独立运行。
*   **`llm-bridge`（智能意图编译器）**：负责将玩家的自然语言意图（如“依山而建的北欧伐木村”）转化为严谨的空间规划参数与建筑风格。提供 Antigravity CLI、自定义大模型 API Key 及无网离线规则三重保障。
*   **`fabric-mod`（游戏内交互与施工落地）**：Minecraft 1.20.1 Fabric 模组。内置全屏 2D 鸟瞰图（Tactical Map）、鼠标悬浮探查、半透明路网矢量预览，以及土方切填、挡土墙砌筑与自适应建筑落地引擎。

最终模组产物为单一 `.jar` 文件，已将上述核心算法与意图编译器一并打包封装着色。

---

## 二、 运行环境要求

1.  **游戏版本**：Minecraft **Java 版 1.20.1**（或 1.20.x）。
2.  **模组加载器**：**Fabric Loader** 0.15.0+。
3.  **运行环境**：**Java 21 LTS**（您的电脑已成功配置 OpenJDK 21）。
4.  **前置模组**：**Fabric API** 对应版本（所有 Fabric 模组通用前置）。

---

## 三、 模组安装与部署步骤

### 步骤 1：获取模组 Jar 包
在当前工程根目录下执行编译打包命令（或直接取用构建产物）：
```bash
.\gradlew.bat :fabric-mod:assemble
```
打包成功后，产物位于：
```
fabric-mod/build/libs/mc-settlement-generator-1.0.0.jar
```

### 步骤 2：放入 Minecraft 模组文件夹
1. 打开您的 Minecraft 游戏目录（通常为 `%appdata%\.minecraft`，或第三方启动器如 HMCL / PCL2 / Prism Launcher 对应的实例目录）。
2. 进入 `mods` 文件夹。
3. 将 `mc-settlement-generator-1.0.0.jar` 和配套的 `fabric-api-0.92.2+1.20.1.jar` 放入其中。

---

## 四、 游戏内操作与使用全流程指南

### 1. 进入测试地形
建议在游戏中选择或生成一个**带有中等坡度、高差约 10~20 格、有树木或河岸**的起伏地形区域（例如森林山坡、平原与丘陵交界处、山谷边缘）。

### 2. 呼出鸟瞰图（Tactical Map）
在游戏内任何位置，按下键盘 **`B` 键**：
*   游戏将弹出全屏 **2D 战术鸟瞰图视口**。
*   系统自动以玩家为中心扫描 $96 \times 96$ 区域内的三维世界体素，并在毫秒级内完成 2.5D 高程、坡度热力图与水体渲染。
*   **视口图例识别**：
    *   `浅绿色 / 深绿色`：平缓草地与承重地表（色阶深浅代表海拔高度）。
    *   `黄绿色`：缓坡地形。
    *   `深褐色`：陡坡与绝壁（系统规划道路时将优先绕行）。
    *   `深蓝色`：河流水面或深水区域。
    *   `墨绿色小点`：树木与地表植被障碍。
*   **鼠标探查器**：在地图上移动鼠标，左上角将实时显示光标处方块的三维绝对坐标 $(X, Y, Z)$ 及局部地表坡度值。

### 3. 输入意图并生成规划
1. 在右侧面板的 **“设计提示词 (Prompt)”** 输入框中，输入您期望的建筑群风格，例如：
   *   `依山而建的北欧伐木小镇，带石砖挡土墙`
   *   `临水而居的渔村，带有河岸码头与阶梯小径`
   *   `高耸山脊上的采矿哨所，紧凑防御风格`
2. 点击 **【生成规划 (Plan)】** 按钮：
   *   系统后台调用求解器，在约 30ms 内完成各向异性等高线寻路与地块切分。
   *   鸟瞰图上将实时浮现**半透明矢量规划层**：
       *   **白色线条**：主干道与平地路面。
       *   **橙色线条**：随坡度爬升自动生成的**石阶梯（Stairs）**。
       *   **黄色线框**：沿路自适应切分的建筑地块，显示地块编号与正门入口标记。
   *   状态栏将显示本次规划的综合质量评分（基于连通性、道路坡度、土方挖填平衡率等）。

### 4. 确认施工并一键落地
1. 观察规划预览，若满意，点击右侧绿色的 **【确认施工 (Construct)】** 按钮。
2. 模组将自动在游戏世界中按严格工程时序执行：
   *   **第一步：净空清障** —— 移除道路走廊与建筑地块内部的杂草、树叶与原木。
   *   **第二步：土方平整（Cut & Fill）** —— 严格按照数学最优标高切削突出山体、回填地势凹陷。
   *   **第三步：护坡挡土墙** —— 沿坡地高差边界修筑石砖挡土墙，彻底杜绝房屋被泥土掩埋。
   *   **第四步：铺路与阶梯** —— 铺设砾石/圆石路面，并在高差处精准安放朝向正确的楼梯。
   *   **第五步：自适应建筑生成** —— 在水平基底上构建房屋，并在底部向地下基岩延伸实体石料柱，**彻底杜绝房屋悬空漂浮**！
   *   **第六步：入户阶梯连接** —— 从每座房屋的正门引出台阶平滑连通至主干道。
3. 关闭界面，您即可在世界中漫步探索生成的立体聚落！

## 五、 大语言模型（LLM）与 API Key 配置

系统在根目录下提供配置文件：`.minecraft/config/mcsettlement.json`。

### 1. 默认开箱即用（无网/离线保底模式）
如果您没有配置任何 API Key，或者处于离线单机状态：
*   系统将自动启用内置的**启发式规则引擎（Heuristic Fallback Engine）**。
*   引擎会根据地形的高差落差、坡度分布与水体面积，自动推理最契合的聚落风格与地块数量。
*   **无需配置任何 Key，100% 保障核心功能可用**！

### 2. 使用自定义大模型 API Key（OpenAI / Gemini / 任意中转站）
若希望使用最强大的大语言模型深度理解复杂提示词，可在配置文件中填入您的密钥：
```json
{
  "llmApiEndpoint": "https://api.openai.com/v1",
  "llmApiKey": "sk-your-api-key-here",
  "llmModelName": "gpt-4o-mini",
  "preferLocalAgy": true,
  "defaultThemePrompt": "依山而建的自然村落，带石质挡土墙与等高线道路"
}
```
*   `llmApiEndpoint`：支持任何兼容 OpenAI 格式的端点（如 `https://api.deepseek.com/v1` 或各类云服务网关）。
*   `llmApiKey`：填入您的 API Key。

### 3. 本地 Antigravity CLI 直连模式
*   若您的电脑已安装 `agy` 命令行工具，且在系统 PATH 中可用：
*   当 `preferLocalAgy` 为 `true` 时，系统将优先通过本地进程管道与 `agy` 交互，无需消耗外网 API 额度。

## 六、 脱机算法验证与快速体验（开发者模式）

在不启动 Minecraft 客户端的情况下，您可以直接在当前工作区运行纯 Java 脱机规划器进行算法测试与预览：

```powershell
.\gradlew.bat :core-planner:run --console=plain
```

运行后将产生如下输出：
1. **控制台 ASCII 鸟瞰图**：直接在终端打印地形地貌、道路走向与地块分布字符画。
2. **`core-planner/output/plan.json`**：导出符合 Planning IR v0.1 规范的完整结构化规划数据。
3. **`core-planner/output/preview.svg`**：导出一张精美的 2D 矢量矢量俯视图，可直接拖入任意浏览器放大查看。

单元测试执行命令：
```powershell
.\gradlew.bat :core-planner:test
```
所有测试均在带有 16 格真实落差的连续曲面地形上进行自动化断言，验证道路连续性、阶梯标记率与土方平衡有效性。
