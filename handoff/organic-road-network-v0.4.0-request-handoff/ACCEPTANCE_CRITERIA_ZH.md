# 验收标准

## 1. 地形非重复

1. 对固定种子和相同参数重复生成，结果必须逐字节确定；改变 `terrainSeed` 必须改变原始地形，改变 `planSeed` 不得改变原始地形。
2. 在 512×512 场景中，对高度、表面材质、植被和水体掩码分别检查常见平移量（至少 16、32、64、96、128 格）；不得出现大面积逐格完全相同的平移瓦片。
3. 输出二维自相关或等价的重复度量及最可疑位移。自然相似允许存在，但不得只用“肉眼看起来不重复”作为结论。
4. 若根因仅在植被/水体采样而非高度场，应分别修复和报告，不得把所有问题笼统归因于噪声。

## 2. 道路拓扑

对参考的 512×512、山地脊线、terrainSeed=42、planSeed=42、目标7栋场景，在满足原有硬约束且完成7/7时：

1. 至少存在一个由建筑或广场语义节点形成的中心枢纽，而不是把任意既有道路格当成唯一生长源。
2. 至少存在两个度数不小于3的真实分支节点；分支必须对应不同可施工道路，不是同一路径的重复边。
3. 至少存在一个可验证回路，图的环秩 `E - V + C >= 1`；回路必须在实际铺装图中连通。若特定地形确实无可施工回路，必须返回明确原因，并用另一个固定可行场景证明回路能力。
4. 道路至少区分主连接、二级连接和局部接入三类；每栋已分配建筑都通过局部接入连接到网络。
5. 至少一个中心产生多个短局部分支（“树突”）和一个或多个较长跨中心连接（“轴突”）。这些名称是拓扑语义，不要求模拟生物神经元。

## 3. 不规则与曲线

1. 不得通过每格随机左右抖动制造曲线；应使用稀疏控制点、曲率代价、方向惯性、等高线偏好、样条采样后栅格化，或能产生等价结果的方法。
2. 非受迫的长道路不得退化为贯穿地图的单一直线；报告最长直线段占该道路长度的比例，并为参考场景加入防回归阈值。
3. 同时禁止锯齿：不得出现高频左右交替或 A-B-A-B 型微摆动。转向应形成可读的长弧、折线弧或顺地形走向。
4. 曲线栅格化后仍须满足全宽碰撞、坡度、台阶朝向、保护区、水体和施工编辑预算。

## 4. 回归与证据

1. 保持既有 core-21、adaptive-29、fuzz-100、桥接测试和API检查通过。
2. 新增具名测试：地形平移重复、枢纽树突/轴突、二级分支、可施工回路、长直线退化、微锯齿、同种子确定性、不同规划种子多样性。
3. 测试必须检查 PlanningIR 和 `groundColumns`，不能只检查浏览器像素。
4. 浏览器至少保存参考场景的原始地形、规划叠加、施工结果三张截图，并记录实际参数、网络指标、规划耗时和预算消耗。
5. 报告所有 PARTIAL、INFEASIBLE、预算耗尽和退化样本；不得只展示成功图。
