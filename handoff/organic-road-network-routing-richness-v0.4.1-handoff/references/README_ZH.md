# 有机道路 + 多尺寸、多形状建筑 · v0.4.0

## 本次直接可用的内容

共 **22 个建筑预设：原10个保留，新增12个**。新增形状为方形、狭长矩形、L、T、U、中庭、十字、八角与阶梯形；同一形状也有不同尺寸。预设是实际方块建筑，不只是预览轮廓。

占地用逐格掩码定义，平台、旋转、间距、道路碰撞、根基和体素施工共同使用。L形凹口和中庭不自动填成外接矩形；包含“凹口/中庭为保护区”的真实规划与施工测试。

浏览器默认 **混合 · 多尺寸/多形状**。也可选原版、紧凑、大体量、单一指定；点击“查看22个建筑占地预设”查看每个预设的外接尺寸、实际占地格数和高度。点选卡片会选中模板，随后点击“生成地形 + 规划”。不会为了凑数偷偷换成小模板。

道路改成中心枢纽、主连接、局部接入、受控二级冗余；所有边实际进入 PlanningIR/groundColumns。参考512山地场景：7/7栋、3枢纽、2真实分叉枢纽、1真实闭环。地形不再使用固定正弦波叠加；材质、植被、水体各有独立重复度量。

## 怎么启动

解压整个包，进入 `source/`。环境为 Java 21、Python 3、本地 Gson（项目声明2.10.1）。Windows PowerShell：

```powershell
.\tools\start_preview.ps1 --port 18766
```

Linux/macOS：

```sh
bash tools/start_preview.sh --port 18766
```

浏览器打开 `http://127.0.0.1:18766/`。本地缓存找不到 Gson 时，先将 `GSON_JAR` 设为自己电脑中真实 Gson jar 的路径。脚本不会自动下载依赖。本包不包含本机系统jar、账户、密钥或缓存。

这不是可直接安装的 Fabric 模组二进制；Fabric完整编译和Minecraft实机仍未验证。

- `IMPLEMENTATION_NOTES_ZH.md`：调用链、两个根因、设计取舍与资源界限。

- `changes.unified.diff`：相对上传的0.3.0源码基线的补丁。
- `evidence/current/`：新测试原始日志、IR、地形通道、API、截图与诊断。
