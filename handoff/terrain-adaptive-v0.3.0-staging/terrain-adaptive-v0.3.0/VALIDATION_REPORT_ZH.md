## 新增29项覆盖范围

全宽足迹测试遍历8/12方向、四象限、宽度1–5和负坐标；与独立的闭线段采样/角点双格审计交叉检查。测试含真实非正交道路、等高线延伸、长坡升降台阶，6组按8/12方向×水/保护区/建筑分类的角格阻挡。它不只检测中心线是否避障。

平台测试要求同一布局多栋不同Y并实际生成楼梯；施工审计读取原始楼梯方块状态，检查半格踏步、头部净空、全部道路边缘格可达，以及从真实门口到入口的连接。缺失一个斜向角格、错误楼梯朝向、重复施工列等篡改会被拒绝。

建筑测试验证开关关闭时不加入45°候选，打开时按真实掩码施工；以只能由45°外接尺寸满足的需求检查非显示层旋转。全部10个预设×4个朝向的45°网格检查门道、完整掩码及掩码外空气。没有为了变容易而减小预设。

预算测试覆盖状态、施工列、编辑、标高传播极小预算；32MiB超响应序列化必须抛错，不能产生截断成功JSON；513地图、10方向、过大预算在分配或规划前拒绝。核心大地图另含128、256、512、192×96、511×257。

确定性测试在剔除墙钟时间/时间戳后比较完整IR及编辑序列；包括负坐标、大矩形图、12方向和45°。HTTP同请求重复时原始地形、施工层、完整预览方案逐字段相同；只roll规划seed时原始地形hash和原始层完全相同。四种地形的构造与仿真施工均有执行检查。

原21项回归保留了场景与预期状态；只把「正交/轴对齐/统一标高」旧审计假设替换为真实全宽、多标高、台阶和掩码审计。用途、尺寸、保护、水、逐格挖填、坡度、间距、退界、硬邻近、门口连通及预算检查仍在。
