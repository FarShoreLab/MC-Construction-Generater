# 可直接复制给其他 AI

请为 MC Settlement 生成新的小中型建筑预设。先完整阅读 README_ZH.md、preset-layout.schema.json、example.layout.json 和 INTEGRATION_ZH.md，严格使用 preset-layout/1。

我需要的主题和数量：【在这里填写，例如：三种有附属仓库的小农舍、磨坊、乡村酒馆】。

建筑需要有可辨认的屋顶、窗户、支柱、门廊和材料层次。占地尺寸应有区别，优先 7–24 格；不得超过 32 格，不得重新启用封存的 48/64/96 大型预设。不要把同一个盒子简单缩放后当成多种预设。

每个预设必须明确预留占地、本体、附属建筑/庭院、候选开口坐标与方向。允许只有本体；需要院落时使用 components 标明 main/annex/courtyard/path/garden，所有组件不重叠且覆盖整块预留占地。院门必须通向主体门和附属门，各入口要两格净空。不要仅添加语义标签而不生成体素。

只生成资产及必要的注册修改，不重构规划器或增加无关功能。交付每栋完整的 .layout.json、编译后的 .native.json、尺寸/组成/入口说明和实际校验结果。运行提供的 Python 编译器；如有完整项目，再运行对应 Java 校验与平地单栋 demo。不能运行的检查明确标注未运行，不得宣称游戏内验证通过。发现格式不一致时以运行的编译器和 Java 数据模型为准，记录差异。

请保留原项目现有预设 ID；新 ID 使用明确的英文 snake_case。组件位置从西北角按 +X 东、+Z 南计算，layers[y][z][x]，y=0 是基础顶面。配置中的 entrances 是组团外部接路口；规划器只选择其中一个，不会自动把所有候选连接到道路。
