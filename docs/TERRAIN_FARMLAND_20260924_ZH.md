# 不规则农田、梯田与新增地形

## 使用

运行 `tools/start_preview.ps1 --port 18769`，打开本地预览。

1. 地形类型选择沙漠、大峡谷、盆地、悬崖、山脉或雪峰，点击“只生成地形” → 验证：显示对应地貌，沙漠有沙层、峡谷有分层岩壁、雪峰高处有积雪。
2. 使用“选址专家”，点击“生成地形 + 规划”，切到“施工结果” → 验证：可用空地生成多块不规则农田；缓坡满足条件时另生成梯田，每列挖填不超过 1 格。
3. 大峡谷保持允许桥梁，使用 128×128、地形种子 42、方案种子 42、起伏 24、默认 7 栋和 16 航向 → 验证：建筑连通，跨谷处为木板吊桥、两岸桥塔、侧边栏杆与悬索，谷底没有桥墩填充。

农田沿真实地表开垦，保留粗泥土边界；两块顺地形田块与一块梯田按空间、坡度及预算尝试生成，田块之间留出间隔。没有可用坡地时不强造梯田。农田配套小屋仍需附近有平整干燥空地。

## 接口

新增 `terrainType`：`desert`、`canyon`、`basin`、`cliff`、`mountain_range`、`snow_peak`。原四种类型及其默认地形体素保持兼容。

雪峰现采用宽山体、多个峰顶与侵蚀起伏，参考原版山地的雪坡、裸岩和低地植被层次，并非直接移植原版生成器。提高 `horizontalScale` 扩大山体；降低 `ridgeSharpness` 展宽峰顶。原山脉类型仍保留山脊形态。

所有地形的 `relief` 范围已扩展至 4–128 格；地表保持在 `baseElevation` 至 `baseElevation + relief` 之间，并非上下各 128 格。`waterLevelRatio=0` 仍关闭水域。预览可使用雪峰、256×256、起伏128、水位0观察山体与雪坡；512×512、基准75、起伏128也纳入接口验证。

大峡谷的陆地跨越自动使用吊桥；桥长仍受 `maxLandBridgeSpan` 约束，离地上限为 36 格。吊桥随道路需求生成；“只生成地形”不预置桥。提高水位后，涉水部分沿用已有水上桥梁规则。

农田和梯田在专家规划中生成，`landUses.terraced` 与施工列的 `terracedFarmland` 标识梯田。吊桥、桥塔和栏杆均写入 `groundColumns`，共享施工预算、障碍检查和原地形复核。

预览通过 `strata` 显示沙漠、峡谷、雪峰实际方块层，悬索按方向显示为细链条。预览材质不是 Minecraft 的完整方块模型。

## 验证

- `python tools/build_offline.py --test --evidence build/terrain-expansion-verification`
- `python tools/verify_terrain_controls.py --base http://127.0.0.1:18769 --out build/terrain-expansion-api`
- 新用例 `TerrainExpansionMain` 检查六类地形的重复性、采样一致性、材质、不规则农田及梯田挖填，并运行默认峡谷完整规划。
- `LandBridgeMain` 增加深沟吊桥、两岸锚点、悬索、不填谷底与行走净空检查。

若规划拒绝，查看页面中的明确原因；可降低目标建筑数、调整方案种子，或在跨度不足时调整陆地架空上限。拒绝方案不执行施工。

本次验证覆盖离线 Java 核心、HTTP 接口和浏览器预览；未运行 Minecraft 客户端内验收。
