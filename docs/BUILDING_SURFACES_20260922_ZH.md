# 建筑组团、路面与农田地表

## 已实现

- 预设从 22 个增加到 37 个：12 个带木构梁柱、窗带、分层坡屋顶和烟囱的中小建筑，以及 48×48、64×64、96×96 三个组团。
- 组团是完整预留地块，包含主楼、附属仓库、小屋、庭院、绿地、内部步道及围边；以一个规划地块计数。庭院不会被公共道路或其他地块穿入。大组团支持四个正交朝向，不进行45度栅格旋转。
- 路面可选择土径、砂砾、圆石、石砖。石砖对应石砖台阶，其余使用圆石台阶；桥面继续使用木板。路面材质进入施工清单、计划哈希、JSON 往返和三维预览。
- 农田保持自然边界和原地形高度，内部改为耕地，边缘为粗泥土；牧场为草方块。农田附近存在平整、干燥且不与既有施工冲突的空地，并满足预算时，增加一间 5×7 配套小屋。未生成时展示原因。配套小屋不占用用户指定的主体地块数量。
- 当前农田属于地表开垦；没有新增灌溉系统和作物。耕地使用真实未灌溉状态，不伪装为永久湿润农田。

## 地图承载量

默认使用“按地图配比”：小型为主、中型为辅，大组团数量不超过目标数量四分之一且最多3处。

- 自动大组团要求地图短边至少为组团边长的4倍：48格从192格地图起，64格从256格起，96格从384格起。
- 另检查连续干燥缓坡、可用土地和现有施工预算。预设占地累计不超过可用缓坡陆地22%，且建筑部分最多分配施工列/施工编辑预算的60%，为道路与农牧地留余量。
- 指定总数超出估算承载量时返回 MAP_CAPACITY_EXCEEDED；真实布局、坡度或路由不满足时仍明确拒绝，不偷偷缩小指定建筑。
- “单一指定预设”可直接选择48/64/96组团，保留用户指定尺寸；地形仍需满足挖填与完整连通检查。大型组团需要连续平缓场地，不会为它解除挖填限制。

## Demo

地址：http://127.0.0.1:18770/

启动：`python tools/build_offline.py`，再运行 `python tools/preview_server.py --port 18770`。

默认128×128案例：7个主体地块、77格农田、90格牧场、1间农田小屋，COMPLETE。

256×256缓坡示例：relief=4、水位=0、树密度=0、目标7、按地图配比；实测为1个64格组团加6个中小建筑，107504次施工编辑。

查看单个96格组团：地图256、relief=4、水位=0、目标1、单一预设选择“96格·领主府邸组团”，最小包围框占图与短长轴比设0；点击生成后切换“施工结果”。该场景已完成真实浏览器三维检查。
