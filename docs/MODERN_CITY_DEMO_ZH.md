# 现代密集城市 Demo

在项目根目录运行 `python tools/preview_server.py --port 8766`，打开 <http://127.0.0.1:8766/modern-city>。城市模式使用 Python 标准库和仓库已有 Three.js，不需要重新编译 Java，也不需要下载前端依赖。旧聚落入口仍为 `/`。

## 算法

以道路为先：不等距分级街网 → 封闭街区 → 用途与中心强度 → 沿街建筑和内部庭院。道路走廊先保留，再安排建筑，避免密集放置后逐栋寻路造成的树状小路。单中心、多中心、均衡布局分别展示集中天际线、多个组团和相对均匀的街区密度。

算法在 `tools/modern_city.py`，浏览器仅负责调用 `/api/modern-city`、显示规划体量和交互。矩形坐标为左上角 `x/z` 与宽深 `w/d`；城市范围为 720 × 720 规划单位。导出的 JSON 包含道路、街区、建筑、公园、中心和指标，同样参数可重复生成同一结果。

## 验收

1. 打开页面，查看默认城市 → Verify：出现密集建筑群、主次道路和绿地，侧栏展示真实生成指标。
2. 切换道路、街区、建筑阶段，并切换俯视 → Verify：道路预留与街区边界清晰，建筑位于街区内部。
3. 切换布局和密度后重新生成 → Verify：单中心、多中心和均衡布局不同，密度控制改变建筑规模。
4. 改变种子、再次使用原种子生成 → Verify：新种子改变布局，原参数还原同一规划；可导出 JSON 检查。
5. 运行 `python tools/test_modern_city.py` → Verify：确定性、道路连通、建筑不相交与不侵占道路等几何检查通过。
6. 保持服务器运行，执行 `python tools/verify_modern_city_api.py --port 8766` → Verify：三种布局、重复请求、资源与原入口、非法参数拒绝通过。

若页面无法连接，先确认预览服务器正在运行且端口相同；若提示地址占用，选择其他端口并相应修改浏览器地址。若出现页面错误，保留错误信息并检查服务器终端输出，不使用旧画面代表本次生成成功。

## 当前边界

这是独立的平地城市规划算法与三维体量 demo。建筑立面为预览表达；尚未连接既有 Java `PlanningIR`、Minecraft 方块施工、建筑预设放置或山地/河流路由。人口指标是由住宅楼面面积推算的演示估计，不能用于真实规划决策。

相关项目与方案取舍见 [研究记录](MODERN_CITY_RESEARCH_ZH.md)。
