# 自然地形现代城市 Demo

本次目标：在原城镇 Demo 的 **同一 Java `TerrainBlockGenerator` 方块地形**上安排现代城市，道路与建筑选址读取该地形的真实高度和水体，局部整地具有明确挖填上限。该 Demo 是本地几何模拟，不代表已通过 Minecraft 施工或游戏客户端验收。

## 原始地形来源

`tools/legacy_city_terrain.py` 调用现有 `preview_server.run_java(..., terrain_only=True)`，进入 `SimulationApiRunner` 原有的 `terrainOnly` 分支。原始流程为 `SimulatedSettlementPipeline.generateTerrain → TerrainBlockGenerator.generateWorld → scanTerrain`，不重新用 Python 合成另一套丘陵。

自然地形固定采用 512 × 512 方块、1:1 坐标、基准高度 58、起伏参数 24。界面 hills 对应原生成器 `rolling_hills`，river 对应原生成器 `valley`；后者是原有谷地及其自然水面，不保证呈现蜿蜒河道。

`terrain.mcLayer` 完整保留旧接口 `original` 对象，包括材质、水位、树木体素和地层。`sourceConfig` 保留源参数、生成器版本与原始世界 hash。`terrain.original[i] = mcLayer.heights[i] + 1`，因为旧接口记录支撑方块的 Y，而地表顶面在 Y+1；水面顶面同样使用旧水位+1。城市规划和平台检查使用这组真实顶面高度。

## 独立验收依据

`tools/test_city_terrain.py` 不调用规划器内部采样、碰撞或统计函数。它直接检查导出的 JSON 几何及高度场，而不是仅判断 `metrics` 是否声称成功。

- `terrain.original` / `terrain.modified`：行优先高度数组，索引为 `z * resolution + x`；每个原始值对应一列方块，512 列占 512 格，`step=1`。
- `terrain.waterMask` / `waterLevel`：自然水体及水位；河床原始高度与施工后高度逐点比较。
- `roads[].points`：实际道路中心纵断面 `{x, y, z}`；共享坐标重建道路图，独立检查高程一致、连通性、环路及纵坡。
- 每段非桥道路中点的完整横截面：采样左右边缘、左右半幅及中心，逐相邻点检查局部横坡，避免仅比较两边导致中间鼓包被抵消。纵坡和横坡均以 12% 为本 Demo 的验收上限，不将其表述为公路设计规范。
- `roads[].bridgeSegments`：桥段的相邻点段索引。桥面与河床分开验证；跨水桥段必须在水位以上。
- `buildings[]`：轴对齐占地 `x/z/w/d` 与基础高程 `baseY`。在四角、边缘、中点及内部网格点，对施工后地形做独立双线性插值，验证整个平台水平且真实落地。
- `blocks[].polygon`：逐边检查边界确实来自实际道路图，并验证有向面积为正。建筑如果带有 `blockId`，完整占地须位于该街区内；外围沿街建筑允许 `blockId=null`。
- `parks[]`：对完整矩形范围检查避水、不重叠建筑和实际道路，不把原平地公园位置直接沿用到新地形。

## 验证步骤

1. 生成 hills/river 各三个样本：`(seed, density, max_edit)` 分别为 `(0, .25, 2)`、`(42, .75, 6)`、`(917, 1, 10)` → 验证：高度场有起伏，挖填不超限，水下地形不变，道路连通且有环路，每栋基础落地并避免建筑/道路碰撞。
2. 同种子对比 hills 与 river → 验证：道路水平几何和建筑选址发生变化，不能只是给旧平面网格增加 Y 值；默认样本仍保有密集建筑及多个城市街区环路。
3. 检查实际道路 → 验证：非桥道路中心端点及中点与施工后地形一致；若生成桥段，桥面必须具有水位净空，桥段子图末端必须接入落地道路节点。原始谷地可能形成宽湖盆，没有合适桥廊时允许不生成桥，不为满足桥数量改造自然水域。
4. 对 `seed=42, density=.75, layout=polycentric, terrain=river` 比较 `max_edit=2/10` → 验证：控制项会改变施工后几何，两个上限都严格满足。
5. 重复固定参数并提交非法参数 → 验证：生成结果一致，未知地形及无效挖填预算被拒绝。

运行：

```powershell
python tools/test_city_terrain.py -v
```
