# 最新同步：独立建筑列表、选址偏好与预设作者标准

日期：2026-09-22。最新 demo：`http://127.0.0.1:18771/`。18768/18769/18770 是之前启动的进程，不作为本次新增 HTTP 参数的验收入口。

## 完成项

1. **独立建筑列表**：34 个活跃预设逐项勾选，指定整数数量；点击“使用此列表”后目标地块数自动求和。关闭项不参与生成。总量 1–64，地图不足或无法接路时明确拒绝。列表不与人工建筑锁定点混用，避免数量被人工点替代。农田配套小屋仍由田边可用空间决定，独立于主体列表。
2. **选址优化**：浏览器/HTTP 默认“平地 / 岸边优先 · 减少清林”。从整块占地计算坡度、整地和树木清理成本，并计入岸线距离和入口接驳长度。原版均衡保留作对照。干燥占地、覆盖率、间距、道路与施工预算仍是约束。
3. **候选入口**：12 个精制预设提供多候选入口，规划器结合位置与旋转选择；保存入口索引、朝向、斜向状态，施工按同一变体还原。旧单入口模型兼容。支持标准配置中的 1–8 个入口，每栋目前只选一个道路接驳口。
4. **大占地封存**：48、64、96 从目录、分类、随机候选及自动容量组合中移除，显式生成被拒绝；原 JSON 保留 archived=true，旧 IR 仍可读取模型。自动配比现在使用中小建筑。
5. **作者标准**：`handoff/building-preset-standard-v1/` 提供 JSON Schema、完整作者示例、运行时示例、Python 编译器、集成说明、可复制的 AI 提示词和源码参考。19×19 示例包含木屋主体、独立仓库、庭院和三个外部开口。示例不占用默认活跃目录名额。

## 使用与继续开发

1. 在 demo 展开“独立建筑开关与数量”，勾选并填写数量，点击“使用此列表” → Verify：目标数量自动等于勾选项总数。
2. 点击“生成地形 + 规划” → Verify：状态 COMPLETE、数量匹配；不够时减少数量或扩大地图，不强行放宽硬约束。
3. 将 `handoff/building-preset-standard-v1.zip` 交给其他 AI，按 `PROMPT_FOR_AI_ZH.md` 补充主题 → Verify：对方输出 `.layout.json` 和编译的 `.native.json`，提供校验记录。
4. 注册新预设后重新编译、单栋平地预演 → Verify：实际占地、门口和附属空间正确，再测试混合生成。

若编译失败，先看对应日志；若新增模型布局失败，先按单栋、平地、关闭斜向验证 mask、入口与 layers。不要靠裁剪占地或静默降低数量掩盖失败。
